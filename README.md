# 🏴‍☠️ Flappy Luffy – Python Game

A fun Python game inspired by **Flappy Bird**, featuring **Luffy from One Piece** as the main character.  
Built using **Pygame** with animations, sound effects, and an interactive scoreboard.

---

## 🎮 Features
- Luffy character animation
- Coins to collect with sound effects
- Background music & jump/crash sounds
- Random pipe generation & collision detection
- Scoreboard with high score tracking
- Landing page, game loop, and restart option
